# FitLog

FitLog is a modern web application designed to help users track their daily fitness activities, monitor workouts, and maintain healthy routines seamlessly. Built with performance and usability in mind, it translates UI/UX designs into a responsive and interactive user experience.

---

## 🛠️ Technologies Used

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & PostCSS
- **Code Quality:** ESLint
- **Design Reference:** Figma

---

## ✨ Key Features

1. **Pixel-Perfect Figma Implementation**
   Faithfully designed navigation bar, branding, and layouts directly translated from the provided Figma prototypes.

2. **Interactive Dashboard & Navigation**
   Clean navigation and interactive components allowing users to easily transition between workout tracking sections.

3. **Responsive & Mobile-First Design**
   Fully optimized interface using Tailwind CSS to deliver an optimal viewing experience across mobile, tablet, and desktop devices.

4. **Structured Workout Logging**
   Intuitive UI forms and cards to log fitness metrics, daily steps, and workout history efficiently.

5. **Type-Safe Development Setup**
   Built with TypeScript and Next.js App Router for strict type checking, fast page loading, and scalability.
